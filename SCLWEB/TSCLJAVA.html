History

A Brief History About Java


Java was created by James Gosling and his team at Sun Microsystems in 1991, originally under the project name Oak. It was designed with the goal of being a platform-independent language for consumer electronics. However, as the internet grew in the 1990s, Java's potential for web development became clear.
Java was officially released in 1995 as Java 1.0, with the promise of "Write Once, Run Anywhere" (WORA), meaning Java applications could run on any device with a Java Virtual Machine (JVM), regardless of the underlying operating system.


Early Development (1991-1995)

1991: Java was originally conceived under the name Oak by James Gosling and Mike Sheridan at Sun Microsystems. It was initially intended for consumer electronics like set-top boxes.
The project was renamed Java in 1994 due to trademark issues with the name Oak.
Java was designed to be platform-independent, allowing applications to run on any device using the Java Virtual Machine (JVM).


Java 1.0 (1995): Official Release

In 1995, Java 1.0 was released by Sun Microsystems, marking the beginning of its journey in the software industry.
Java introduced the concept of "Write Once, Run Anywhere" (WORA), meaning Java programs could run on any system that had the JVM installed, making it platform-independent.
The language quickly gained traction for web development due to the rise of the internet, especially with the introduction of Java Applets, which were small programs embedded in web pages.


Java 2 (J2SE, J2EE, J2ME) (1998)

In 1998, Java 2 was introduced with the first major split into three editions:
- J2SE (Java 2 Standard Edition): Core platform for desktop and server applications.
- J2EE (Java 2 Enterprise Edition): A set of APIs for building large-scale enterprise applications (introducing technologies like Enterprise JavaBeans (EJB) and Servlets).
- J2ME (Java 2 Micro Edition): A platform for mobile and embedded devices, marking Java early entry into the mobile industry.


Java 5 (2004): A Major Update

Java 5 (also known as J2SE 5.0) was released in 2004, and it introduced several important features:
- Generics: Allowed for type-safe data structures.
- Metadata Annotations: Introduced a way to add metadata to classes and methods.
- Enhanced For Loop: A more concise way to iterate over collections.
- Varargs: Allowed methods to accept a variable number of arguments


Java 6 (2006): Performance Improvements

Java 6 focused on improving performance, stability, and support for web applications.
New features included scripting support via the Java Compiler API, performance optimizations, and better integration with web technologies.


Java 8 (2014): A Revolutionary Release

- Lambda Expressions: Allowed for functional programming features, enabling more concise and parallel-friendly code.
- Streams API: A new abstraction for handling sequences of data, allowing developers to write declarative code for processing data.
- Default Methods: Allowed interfaces to have methods with default implementations.
- New Date and Time API: Replaced the outdated Date and Calendar classes.

Java 9 (2017): Modularity

Java 9 introduced the module system (Project Jigsaw), allowing developers to modularize applications and the Java platform.
This made the language more scalable and maintainable, especially for large applications.


Java 10 (2018) and Java 11 (2018): Six-Month Release Cycle

With the release of Java 10, Oracle introduced a six-month release cycle for Java, allowing faster innovation and feature delivery.
Java 11 became the first LTS (Long-Term Support) release under the new cadence. It also introduced Flight Recorder (a tool for monitoring Java applications) and the HTTP Client API.


Java 12 to Java 16 (2019–2021): Continuous Updates

    These versions saw incremental updates, including:

  • Java 12: Introduced Shenandoah Garbage Collector and JVM improvements.
  • Java 13: Included Text Blocks (for easier handling of multi-line string literals).
  • Java 14: Featured JEP 358 for Helpful NullPointerExceptions and records (preview).
  • Java 15: Introduced sealed classes (preview) for better inheritance control.


Java 17 (2021): Another LTS Release

Java 17 is the latest LTS release, offering long-term support and many important updates:
- Sealed Classes: Allowed more control over class hierarchies.
- Pattern Matching (Preview): Simplified type matching.
- Various performance improvements and API enhancements.

Introduction to Java

What is Java?


Java is one of the most popular and widely used programming languages in the world. It is a versatile, object-oriented, and platform-independent language that has been a staple in both the academic and professional software development fields for decades. Java is used in a variety of domains, from mobile applications (especially Android) to large-scale enterprise systems, web applications, and more.

Key Features of Java:


  • Platform Independence
    - Java follows the principle of "write once, run anywhere," meaning that Java programs can be run on any device that has a Java Virtual Machine (JVM). The compiled code (bytecode) is not dependent on a specific system's architecture, which makes Java platform-independent.
  • Object-Oriented Programming (OOP)
    - Java is an object-oriented programming (OOP) language. It promotes the concepts of classes and objects, where:
    Classes define the structure and behavior of objects.
  • Simplicity
    - Java is designed to be simple and easy to learn. Its syntax is clean and mostly derived from C++, which makes it familiar to many programmers.
    - It removes complex features like pointers and manual memory management, which are present in languages like C and C++.
  • Robustness
    - It refers to the language's ability to handle errors effectively, manage unexpected situations, and ensure stability and reliability in applications. Java's design emphasizes error detection, exception handling, memory management, and the avoidance of common programming pitfalls. Java programs are expected to run smoothly even in the presence of unexpected situations, ensuring higher application reliability and fewer crashes.
  • Security
    - Java is known for its strong security model, which is a fundamental part of its design. The language and platform provide various features and mechanisms to ensure that Java applications can be run securely, preventing unauthorized access and protecting the system from malicious activities.
  • Multithreading
    - Java is known for its strong security model, which is a fundamental part of its design. The language and platform provide various features and mechanisms to ensure that Java applications can be run securely, preventing unauthorized access and protecting the system from malicious activities.
  • Rich API
    - Java provides a rich set of APIs that empower developers to create robust, portable, and feature-rich applications. These APIs cover a wide range of functionalities, making Java one of the most versatile programming languages.
  • Distributed Computing
    - Java is widely used in distributed computing due to its robust libraries, support for multithreading, and platform-independent nature. Java provides a range of tools and APIs for building distributed systems, allowing developers to create scalable, fault-tolerant, and high-performance applications that run across multiple machines or nodes.
  • Automatic Garbage Collection
    - Collection (GC) in Java is an automatic process that helps manage memory by reclaiming the memory that is no longer in use, preventing memory leaks, and ensuring that programs use memory efficiently. Java provides automatic garbage collection, which means that developers do not need to manually allocate or deallocate memory. Instead, the Java Virtual Machine (JVM) handles this process in the background.
    - Garbage Collection is a critical feature in Java because it simplifies memory management and helps prevent common errors such as memory leaks and dangling pointers, which are often encountered in languages that require manual memory management like C and C++.

Why do we use Java?


Java is a versatile, secure, and powerful programming language that can be used for developing a wide range of applications, from mobile and web apps to large-scale enterprise systems and distributed computing solutions. Its platform independence, ease of use, rich libraries, and continuous evolution make it an excellent choice for both beginners and experienced developers. Whether you're building a small mobile app or a large, complex enterprise system, Java remains one of the most reliable and widely-used programming languages in the world.

Variable & Datatypes

In Java, a variable is a named container used to store data that can be referenced and manipulated during the program's execution. Every variable has a data type, which defines the kind of data it can store, such as numbers, characters, or true/false values. Java has two main categories of data types: primitive data types, which include types like int, float, and boolean, and reference data types, such as String and arrays, which store references to objects. Primitive data types hold simple values directly, while reference types hold memory addresses pointing to complex data structures. Choosing the correct data type for a variable ensures proper storage, memory efficiency, and support for required operations.


Variables


Variable are used to store up temporary data to be used in our program's runtime.


In C#, there are different types of variables (defined with different keywords), for example:


  • int - stores integers (whole numbers), without decimals, such as 123 or -123
  • double - stores floating point numbers, with decimals, such as 19.99 or -19.99
  • char - stores single characters, such as 'a' or 'B'. Char values are surrounded by single quotes
  • string - stores text, such as "Hello World". String values are surrounded by double quotes
  • bool - stores values with two states: true or false

Identifiers


An identifier is the name you give to a program element, such as a variable, function, class, or constant. Identifiers are used to reference and manipulate the data in your program. In C#, identifiers must follow specific rules, which are designed to ensure that the code is readable and avoids conflicts with the language's reserved keywords.


Rules for Identifiers :


  • Start with a letter or an underscore: An identifier can start with a letter (A-Z or a-z) or an underscore (_), but it cannot start with a digit.

  • Valid: age, _myVariable, customerName
  • Invalid: 2ndVariable (starts with a digit)

  • Can include letters, digits, and underscores: After the first character, the identifier can contain letters, digits (0-9), and underscores.

  • Valid: userName_123, customer1, _value

  • Cannot be a reserved keyword: C# has a set of reserved keywords that are part of the language syntax. These cannot be used as identifiers.

  • Reserved keywords (examples): int, class, if, while, public, static, void, true, false.

  • Case-sensitive: C# is case-sensitive, meaning myVariable and myvariable would be treated as two different identifiers.


Declaring Variables


Declaring a variable in C# means specifying its data type and giving it a name. The type of the variable determines the kind of data it can store (e.g., numbers, text, boolean values). The declaration of a variable is always done by stating the type followed by the variable's name.


In C#, variables must be declared before they are used. This is because C# is a statically-typed language, meaning the type of the variable is known at compile-time.


Assigning Variables


Assigning a variable means giving it a value. This is done using the assignment operator 😊). Once a variable is declared, you can assign a value to it either when you declare it or afterward. The value must match the variable's type.


In C#, variables are strongly typed, meaning the value assigned to the variable must match its declared type. If you try to assign a value of the wrong type, you'll get a compile-time error.


Printing Variables


To output information to the console in C#, you use the Console.WriteLine() method. This method prints the value of a variable or a string to the console, followed by a newline character.


Concatenation


Concatenation refers to joining two or more strings into a single string. In C#, this can be done using the + operator.
