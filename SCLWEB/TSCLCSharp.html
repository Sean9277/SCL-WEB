History

A Brief History About C#


C# (pronounced "C-sharp") is a modern, object-oriented programming language developed by Microsoft. Its history is closely tied to the evolution of the .NET framework and the need for a language that could leverage the capabilities of the Windows platform.


Origins (Late 1990s)

Development: C# was developed by Anders Hejlsberg and his team at Microsoft. The language was designed as part of the .NET initiative, which aimed to create a new platform for building applications that could run on Windows and the web.
Influences: C# was influenced by several programming languages, including C++, Java, and Delphi. It aimed to combine the best features of these languages while providing a simpler and more productive programming experience.


C# 1.0 (2000)

Release: C# was officially released in 2000 alongside the first version of the .NET Framework (1.0).
Features: The initial version included features such as strong typing, garbage collection, and support for object-oriented programming.


C# 2.0 (2005)

Enhancements: This version introduced generics, anonymous methods, and nullable types, which significantly improved the language's expressiveness and type safety.
Integration: C# 2.0 was released with .NET Framework 2.0, which included many new libraries and tools.


C# 3.0 (2007)

LINQ: One of the most significant features introduced in C# 3.0 was Language Integrated Query (LINQ), which allowed developers to write queries directly in C#.
Other Features: This version also introduced lambda expressions, extension methods, and automatic properties, enhancing the language's capabilities for functional programming.


C# 4.0 (2010)

Dynamic Typing: C# 4.0 introduced dynamic typing with the dynamic keyword, allowing for more flexibility in working with types at runtime.
Named and Optional Parameters: This version also added support for named and optional parameters, making method calls more readable.


C# 5.0 (2012)

Asynchronous Programming: C# 5.0 introduced the async and await keywords, which

C# 6.0 (2015)

Simplifications: This version focused on simplifying the syntax with features like interpolated strings, expression-bodied members, and null-conditional operators.


C# 7.0 (2017)

New Features: C# 7.0 introduced several new features, including tuples, pattern matching, local functions, and out variables, enhancing the language's expressiveness.


C# 8.0 (2019)

Nullable Reference Types: This version introduced nullable reference types, which help developers avoid null reference exceptions.
Other Features: C# 8.0 also included asynchronous streams, switch expressions, and indices and ranges.


C# 9.0 (2020)

Records: C# 9.0 introduced records, a new reference type that provides built-in functionality for immutability and value-based equality.
Init-only Properties: This version also added init-only properties, allowing properties to be set during object initialization.


C# 10.0 (2021)

Improvements: C# 10.0 introduced features like global using directives, file-scoped namespace declarations, and improvements to pattern matching.


C# 11.0 (2022)

Latest Features: C# 11.0 introduced features such as raw string literals, required members, and generic math, further enhancing the language's capabilities.

Variables and Data Types

Variables


Variable are used to store up temporary data to be used in our program's runtime.


In C#, there are different types of variables (defined with different keywords), for example:


  • int - stores integers (whole numbers), without decimals, such as 123 or -123
  • double - stores floating point numbers, with decimals, such as 19.99 or -19.99
  • char - stores single characters, such as 'a' or 'B'. Char values are surrounded by single quotes
  • string - stores text, such as "Hello World". String values are surrounded by double quotes
  • bool - stores values with two states: true or false

Data Types


A data type specifies the size and type of variable values. It is important to use the correct data type for the corresponding variable; to avoid errors, to save time and memory, but it will also make your code more maintainable and readable.

The most common data types are:


Identifiers


An identifier is the name you give to a program element, such as a variable, function, class, or constant. Identifiers are used to reference and manipulate the data in your program. In C#, identifiers must follow specific rules, which are designed to ensure that the code is readable and avoids conflicts with the language's reserved keywords.


Rules for Identifiers :


  • Start with a letter or an underscore: An identifier can start with a letter (A-Z or a-z) or an underscore (_), but it cannot start with a digit.

  • Valid: age, _myVariable, customerName
  • Invalid: 2ndVariable (starts with a digit)

  • Can include letters, digits, and underscores: After the first character, the identifier can contain letters, digits (0-9), and underscores.

  • Valid: userName_123, customer1, _value

  • Cannot be a reserved keyword: C# has a set of reserved keywords that are part of the language syntax. These cannot be used as identifiers.

  • Reserved keywords (examples): int, class, if, while, public, static, void, true, false.

  • Case-sensitive: C# is case-sensitive, meaning myVariable and myvariable would be treated as two different identifiers.


Declaring Variables


Declaring a variable in C# means specifying its data type and giving it a name. The type of the variable determines the kind of data it can store (e.g., numbers, text, boolean values). The declaration of a variable is always done by stating the type followed by the variable's name.


In C#, variables must be declared before they are used. This is because C# is a statically-typed language, meaning the type of the variable is known at compile-time.


Assigning Variables


Assigning a variable means giving it a value. This is done using the assignment operator (=). Once a variable is declared, you can assign a value to it either when you declare it or afterward. The value must match the variable's type.


In C#, variables are strongly typed, meaning the value assigned to the variable must match its declared type. If you try to assign a value of the wrong type, you'll get a compile-time error.


Printing Variables


To output information to the console in C#, you use the Console.WriteLine() method. This method prints the value of a variable or a string to the console, followed by a newline character.


Concatenation


Concatenation refers to joining two or more strings into a single string. In C#, this can be done using the + operator.

User Input

Console.ReadLine() in C#


In C#, Console.ReadLine() is a method of the Console class in the System namespace, primarily used to read input from the user via the console (command line or terminal). The method enables interactive user input, allowing users to provide information or make choices during the execution of a console application.


User Interaction: When the program calls Console.ReadLine(), it pauses and waits for the user to type a line of text. Once the user types something and presses the Enter key, Console.ReadLine() reads the input and returns the entire line as a string.


Console.Read() in C#


Console.Read() is a method from the Console class that reads a single character from the console input. It does not wait for the Enter key, but instead waits for a single key press and returns the character that was pressed as an integer, which represents the character's ASCII (or Unicode) value.


Console.ReadKey()


The Console.ReadKey() method is part of the System namespace, and it reads a single key press from the console. Unlike Console.Read(), which returns the ASCII value of the pressed key as an integer, or Console.ReadLine(), which captures an entire line of text, Console.ReadKey() provides more detailed information about the key press.



Difference of Console.ReadLine, Console.Read, and Console.ReadKey


Console.ReadLine() captures an entire line of input from the user, including spaces, and returns it as a string after the user presses Enter. It's useful for scenarios requiring multi-word input like names or commands.


Console.Read() reads a single character and returns its ASCII value as an integer. It doesn't wait for Enter and is commonly used for capturing single character inputs, such as menu choices.


Console.ReadKey() also captures a single key press but provides more detailed information via a ConsoleKeyInfo object. This includes the key pressed, the character, and any modifier keys (e.g., Ctrl, Shift). It's ideal for detecting specific keys or handling key combinations in interactive applications like games or menus.


Summary


In summary, Console.ReadLine() is for capturing full lines of input, Console.Read() is for reading a single character's ASCII value, and Console.ReadKey() offers a more detailed way of handling key presses, allowing you to detect modifiers and special keys.

Data Type Conversion

Data Type Conversion


In C#, data type conversion refers to the process of converting one data type to another. This can happen in two primary ways: implicit conversion and explicit conversion (type casting). C# provides different mechanisms for converting between types, such as built-in type casting, conversion methods, and parsing methods.


Type Casting


Type casting in C# is the process of converting a variable from one type to another. This can be necessary when you want to perform operations on different data types or when you want to store a value of one type in a variable of another type. There are two main types of casting in C#: implicit casting and explicit casting.


Implicit Casting


Implicit casting (also known as automatic casting) occurs when the conversion is safe and no data will be lost. This usually happens when converting from a smaller data type to a larger data type. For example, converting an int to a double.

Explicit Casting


Explicit casting (also known as manual casting) is required when you are converting from a larger data type to a smaller data type, or when there is a possibility of data loss. This is done using a cast operator.

Conversion Methods


C# provides several conversion methods in the Convert class and the Parse methods to convert between types, especially when dealing with strings or when you want to safely handle conversions. These methods handle cases that may throw exceptions (like InvalidCastException) if the conversion is not valid.

Arrays

Arrays


In C#, arrays are used to store multiple values of the same type in a single variable. Arrays provide a convenient way to group related data together. They allow you to work with large amounts of data efficiently by using an index to access each element.


Declaring Arrays


An array in C# is declared by specifying the type of elements it will hold, followed by square brackets ([]) and the array name. Arrays are zero-indexed, meaning the first element is at index 0, the second at index 1, and so on.

Accessing Arrays


You can access individual elements of an array by using the index. The index is a zero-based integer that represents the position of the element.

Paired Arrays by Index


In C#, when you talk about paired arrays by index, it generally refers to associating elements from two or more arrays based on their indices. For example, you might want to combine two arrays (one holding names and the other holding ages) in such a way that each element in the first array corresponds to the element in the second array by index.

Conditionals

Conditional Statement


Conditionals are statements in programming that allow your code to execute different blocks of code based on certain conditions. In C#, conditionals are commonly written using the if, else, else if, and nested conditional structures, combined with relational and logical operators to create complex decision-making behavior.


Relational Operators


Relational operators are used to compare values and determine the relationship between them. They return a boolean value (true or false) depending on the comparison.


  • == : Equal to
  • != : Not equal to
  • > : Greater than
  • < : Less than
  • >= : Greater than or equal to
  • <= : Less than or equal to

Examples :

if Statement


The if statement allows you to execute a block of code only if a specified condition is true. It's one of the most fundamental control flow structures.

In this example, the program checks if age is greater than or equal to 18. Since the condition is true, it will print "You are an adult.".


if - else Statement


The if - else statement allows you to provide an alternate code block to execute when the condition in the if statement is false.

Here, since age is not greater than or equal to 18, the condition is false, and it prints "You are a minor.".


if - else if - else Statement


The if - else if - else structure allows you to check multiple conditions. You can have more than one else if to test additional conditions. If none of the conditions are true, the else block will execute.

In this example:

The program checks if score is greater than or equal to 90, in which case it prints "A".
If not, it checks if the score is greater than or equal to 80, and if true, it prints "B".
If neither of the previous conditions is true but score is greater than or equal to 70, it prints "C".
If none of these conditions are true, it prints "Fail".


Nested Conditionals


A nested conditional occurs when you place one if, else if, or else statement inside another. This allows for more granular decision-making.

In this example, the program first checks if age is greater than or equal to 18. If true, it then checks whether the user has a license (hasLicense). If both conditions are true, it prints "You can drive.".


Equals Methods


The Equals() method is used to compare the values of two objects to determine if they are the same. Unlike the relational operators that are often used for primitive types, Equals() is typically used for comparing objects, such as strings or custom classes.


In this case, Equals() checks if the content of str1 and str2 are the same (both are "Hello"), so it returns true. For str1 and str3, it returns false because "Hello" is not equal to "World".


Logical Operators


Logical operators allow you to combine multiple conditions to form more complex boolean expressions. These are typically used inside if statements to make decisions based on multiple conditions.


In this example, the && operator ensures that both conditions are true (age >= 18 and has a license) before the user is eligible to drive. If either condition is false, the else block will execute.

Switch Statements

Switch Statement


The switch statement in C# is a control flow structure that allows you to execute one of many code blocks based on the value of a variable or expression. It is often used when you need to check multiple possible conditions for a single variable and execute different code depending on its value. The switch statement is an alternative to using multiple if - else if statements, especially when you have many conditions to check.


Case Keyword


Defines a possible value of the expression being evaluated. Each case has its own code block that runs if the expression matches that value.

Default Keyword


The default keyword is used to handle cases where no case matches the value of the expression. It is optional but useful for handling unexpected or invalid input. If no case matches and a default block exists, the code inside the default block will be executed.

Break Keyword


The break keyword is used to exit the switch statement once a matching case is found and its block of code is executed. Without the break, the program will continue to execute the subsequent case blocks (this is called "falling through").
