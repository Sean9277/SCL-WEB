Python

History

--The Beginnings (Late 1980s to Early 1990s)--

Creator: Python was conceived by Guido van Rossum in December 1989 during his work at the Centrum Wiskunde & Informatica (CWI) in the Netherlands.

Inspiration: Guido wanted to create a language that would bridge the gap between C and the high-level scripting languages of the time, such as ABC. He was particularly influenced by:

ABC language: Known for its simplicity and error handling.
Other languages: Such as C, Modula-3, and Unix shell scripting.

First Release: The first official version, Python 0.9.0, was released in February 1991. It already included features like:

• Functions and exception handling.

• The module system.

• Core data types like str, list, dict, and int.

-- Python 1.x Era (1991–2000)--

Python 1.0 was released in January 1994. It introduced significant features:

• Functions, lambda, and exception handling.

• The map, filter, and reduce functions.

Community and adoption grew during this period, largely thanks to Python's clean syntax and extensibility.

-- Python 2.x Era (2000–2010) --

Python 2.0: Released in October 2000, it introduced many new features:

• List comprehensions.

• A garbage collection system based on reference counting and cyclic garbage collection.

• Support for Unicode.

Challenges: The 2.x series introduced some inconsistencies and design flaws, leading to long-term issues, particularly regarding Unicode and the division of integers (int/int)

-- Python 3.x Era (2008–Present)--

Python 3.0: Released in December 2008, it was a major overhaul that broke backward compatibility to fix many issues in Python 2.x. Key changes included:

• Print as a function: print() instead of print.

• Division behavior: / for true division, // for floor division.

• Enhanced Unicode support: Strings are str (Unicode) by default.

• Improved standard library organization and consistency.

Python 2.x End of Life: Support for Python 2 ended on January 1, 2020, pushing developers toward Python 3.

--Modern Python (Post-2010)--

Frequent Updates: Python follows a robust release cycle, with significant updates every 18–24 months.

Community Growth: Python became immensely popular due to:
• Extensive libraries like NumPy, Pandas, TensorFlow, and Django.
• Applications in data science, AI, web development, and automation.

Key Modern Features: • Type hints and gradual typing. • Asynchronous programming with async and await. • Pattern matching (introduced in Python 3.10).

--Python Today--

Python is one of the most widely used programming languages globally, known for:

• Its simplicity and beginner-friendly syntax.
• A vast and supportive community.
• Applications ranging from web development and automation to data science, machine learning, and artificial intelligence.

Python Introduction

What is Python

Python is a popular programming language. It was created by Guido van Rossum, and released in 1991.

It is used for:

• web development (server-side),
• software development,
• mathematics,
• system scripting.

What can Python do?

• Python can be used on a server to create web applications.
• Python can be used alongside software to create workflows.
• Python can connect to database systems. It can also read and modify files.
• Python can be used to handle big data and perform complex mathematics.
• Python can be used for rapid prototyping, or for production-ready software development.

Why Python?

• Python works on different platforms (Windows, Mac, Linux, Raspberry Pi, etc).
• Python has a simple syntax similar to the English language.
• Python has syntax that allows developers to write programs with fewer lines than some other programming languages.
• Python runs on an interpreter system, meaning that code can be executed as soon as it is written. This means that prototyping can be very quick.
• Python can be treated in a procedural way, an object-oriented way or a functional way.

Good To Know

• The most recent major version of Python is Python 3, which we shall be using in this tutorial. However, Python 2, although not being updated with anything other than security updates, is still quite popular.
• In this tutorial Python will be written in a text editor. It is possible to write Python in an Integrated Development Environment, such as Thonny, Pycharm, Netbeans or Eclipse which are particularly useful when managing larger collections of Python files.

Python Syntax compared to other programming languages

• Python was designed for readability, and has some similarities to the English language with influence from mathematics.
• Python uses new lines to complete a command, as opposed to other programming languages which often use semicolons or parentheses.
• Python relies on indentation, using whitespace, to define scope; such as the scope of loops, functions and classes. Other programming languages often use curly-brackets for this purpose.
